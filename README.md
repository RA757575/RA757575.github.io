## 🚀 Key Projects & Research

### 1. Smart University Handbook (SUH) 🎓🤖
- **Domain:** AI-Driven Academic Assistance & Mobile Security
- **Tech Stack:** Flutter, Fine-Tuned LLaMA 3, Firebase, RBAC, REST APIs
- **Description:** Graduation project supervised by Dr. Ezzeldeen Al-Mikhlafi. An intelligent academic ecosystem serving Taiz University students with fine-tuned conversational AI, real-time sync, and robust role-based access control.

### 2. Hybrid XAI NIDS (Digital Twin Network IDS) 🛡️🔬
- **Domain:** Machine Learning & Network Threat Detection
- **Tech Stack:** Python, Autoencoder, Isolation Forest, LSTM, XGBoost, SHAP, GNS3, Wireshark
- **Description:** Cutting-edge research constructing a network Digital Twin to detect multi-stage cyberattacks, enhanced with eXplainable AI (SHAP) for transparent, auditable security analyst decision-making.

### 3. Souq Yemen E-Commerce 🛒📱
- **Domain:** Production Mobile Application
- **Tech Stack:** Flutter, Clean Architecture, Supabase PostgreSQL with RLS, Hive Offline-First
- **Description:** Full-scale multi-vendor e-commerce application with resilient offline synchronization, localized Yemeni governorates support, and strict database row-level security.

### 4. GigatopX EduCloud / Oasis Learning Nexus ☁️📚
- **Domain:** Cloud SaaS Architecture
- **Tech Stack:** React, TypeScript, Vite, Tailwind CSS, Supabase, Drizzle ORM
- **Description:** High-performance multi-tenant SaaS educational platform featuring role isolation, live classrooms, dynamic curriculum trees, and interactive assessments.

### 5. SOC Home Lab & Threat Hunting Suite 🔍💻
- **Domain:** Security Operations Center (SOC)
- **Tech Stack:** ELK Stack (Elasticsearch, Logstash, Kibana), Docker, Suricata, Zeek, Sysmon, Kali Linux
- **Description:** Full-fledged threat detection and log analysis lab simulating adversary tactics (MITRE ATT&CK) with automated alerting rules and network telemetry inspection.

### 6. Secure Employee Management System 🏢🔐
- **Domain:** Secure Software Engineering & DevSecOps
- **Tech Stack:** Python Flask, SQLite, OWASP ZAP, SonarQube, Bandit
- **Description:** Hardened employee records system designed to counter OWASP Top 10 vulnerabilities (SQLi, XSS, CSRF, IDOR) with static and dynamic code auditing.
